## 👨‍💻 The Developer Behind the Code

Hey! I'm **Amr Fathi**, a software developer passionate about technology, problem-solving, and the art of creating digital experiences.

I enjoy exploring both the creative and technical sides of software development—from crafting detailed user interfaces to understanding the programming logic and systems that make applications work.

### What matters to me

- **Code quality:** Clear structure, meaningful naming, and reusable logic.
- **First principles:** Understanding how languages, APIs, and systems behave.
- **Design thinking:** Making interfaces feel cohesive instead of merely functional.
- **Curiosity:** Investigating the details that other people might overlook.
- **Consistency:** Making gradual progress rather than chasing every new trend.
